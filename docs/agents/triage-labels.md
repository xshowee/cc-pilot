# 分诊标签

各 skill 使用五个标准分诊角色来描述状态。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签     | 含义                           |
| -------------------------- | -------------------- | ------------------------------ |
| `needs-triage`             | `needs-triage`       | 需要维护者评估该 issue         |
| `needs-info`               | `needs-info`         | 等待提出者补充更多信息         |
| `ready-for-agent`          | `ready-for-agent`    | 已完整明确，可交给 AFK agent   |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                   |
| `wontfix`                  | `wontfix`            | 不予处理                       |

当 skill 提到某个角色（例如 "apply the AFK-ready triage label"）时，使用此表中对应的标签字符串。

如需改用其他词汇，修改「本仓库使用的标签」一列即可。
