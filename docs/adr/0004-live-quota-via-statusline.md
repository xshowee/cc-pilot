# 实时额度靠状态栏被动接收，不在后台请求

"套餐实时剩余百分比"不通过定时请求额度接口实现，而是读取 Claude Code 每次请求后自己拿到、经状态栏转交的 `rate_limits`。cc-pilot 不因此发任何网络请求，"刷新永远手动"的约定保持不变；没有会话在运行的账号，仍靠手动刷新获得额度。

## Considered Options

- **后台定时请求额度接口**：任何账号都能实时显示。没有采用：推翻了"不在后台自动刷新"的约定，多档案多账号下请求量成倍增加，更容易触发接口的 403/429 频率限制，而且是在用 Claude Code 的凭据替它发额外请求。

## Consequences

- 只有交互式会话才运行状态栏；`-p`、IDE 插件等入口的会话不会更新实时额度。
- 需要接入每个档案自己的 `statusLine`（ADR 0003 之后各档案一份），并保留用户原有的状态栏输出。
